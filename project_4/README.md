# Автотесты для формы логина: Java, Selenide, JUnit 5

Проект по [автоматизации UI-тестов](./login-autotests/src/test/java/LoginTest.java)

## Что тестируется:

- **Стенд:** [qa-stand-login.inzhenerka.tech](http://qa-stand-login.inzhenerka.tech/login)
- **Функциональность:** форма входа (логин, пароль, кнопка «Войти»), выход из системы

## Технологии:

- Java 21
- Selenide 7.18.1
- JUnit 5
- Maven

## Что было сделано:
- Были проведены позитивные и негативные сценарии тестирования
- Использованы различные типы локаторов в тестах (CSS, By, XPath, текстовые)
- Был найден баг с возможность входа в систему с пустыми полями
