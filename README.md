# Привет!
Я начинающий специалист по тестированию. В этом репозитории собраны примеры моей тестовой документации.

## Навыки и инструменты
- Тест-дизайн: классы эквивалентности, граничные значения
- Документация: чек-листы, тест-кейсы, баг-репорты, тест-план
- Инструменты: Selenide, JUnit 5, Maven, GitLab, GitHub, Postman, Charles Proxy, DevTools, Android Studio, VS Code, IntelliJ IDEA, PyCharm, pgAdmin, Jira, Яндекс Трекер
- Языки программирования: основы SQL, Java, Python, C, Bash
- Дополнительно: понимание клиент-серверной архитектуры, REST API

## Проекты:
- **[Автотесты для формы логина: Java, Selenide, JUnit 5](./project_4/)** — **автоматизация UI-тестов**: позитивные/негативные, использование разных типов локаторов, SQL-инъекция, граничные значения.
- **[Ручное тестирование веб-формы: чек-лист, тест-кейсы и баг-репорты](./project_1/)** — функциональное тестирование формы заявки на реальном сайте [fitness-cccp.ru](https://fitness-cccp.ru/). Здесь находятся мои **чек-листы, тест-кейсы, баг-репорты**. Использован Chrome DevTools.
- **[Тестирование мобильного трафика через Charles Proxy](./project_2/)** — перехват и модификация трафика на реальных и учебных сайтах через **Charles Proxy** на эмуляторе Android Studio.
- **[Тестирование API с помощью Postman](./project_3/)** — **коллекция запросов**, сниппеты (httpbin.org).
